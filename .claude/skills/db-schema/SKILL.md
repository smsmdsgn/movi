データベース設計に関する規約。詳細は `docs/design.md` 6.1 / 6.2 / 13.2 / 13.3 を参照する。

- 命名規則（13.2）と型の規約（13.3）に従う
- テーブル名に区分接頭辞（`m_` / `t_` / `c_`）を付し、モデルに `$table` を明示する
- `users` およびフレームワーク標準テーブルには接頭辞を付さない
- 金額は円単位の整数、区分は backed enum
- 過去データを削除しない設計とする（6.2）
- 一意制約が必要な箇所（`t_reservation_seats`, `t_seat_locks`, `t_stamps`, 各コード列）を確認する
- キャンセルを伴うテーブルでは生成列による一意制約を検討する（6.4.2）
