予約フローの実装に関する規約。詳細は `docs/design.md` 4.3 / 4.4 / 6.4 / 8.2 / 13.4.6 / 13.4.7 を参照する。

- ロック操作は `SeatLockService` に集約する
- 選択可否の判定は必ずサーバー側のロック取得結果による
- ロックは10分、決済画面遷移時に15分へ延長する
- 1利用者あたり1上映回・8席まで
- 予約確定は単一トランザクション。ユニーク制約違反時は返金してやり直し
- 予約確定トランザクションの手順1として、ロック所有権と期限を再検証する（6.4.2、8.2）。失敗時はロールバックのうえ返金する（ユニーク制約違反時と同じ経路。8.2「決済失敗時の扱い」表とは別）
- ログイン・会員登録の完了時は `SeatLockService::transfer()` で座席ロックの `holder_key` を引き継ぐ（13.4.6）
- キャンセル時は無料鑑賞券を戻し、`released_at` を設定して座席を再販可能にする
- `released_at` は親の `status` 変更と同一トランザクションで更新する
